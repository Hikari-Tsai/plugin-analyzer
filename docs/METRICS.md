# 指標說明：每個分析在測什麼

這份文件用白話解釋 Plugin Analyzer 的每個分頁和數字：**它在測什麼、圖要怎麼看、什麼數值算好**。
不需要先懂數位訊號處理；遇到術語時，文中會順便解釋。

---

## 先懂三件事

### 1. 量測的原理：送已知的訊號，看出來變成什麼
Plugin Analyzer 不會去讀插件的程式碼，而是把插件當成一個「黑盒子」：

```
已知的測試訊號 ──▶ [ 插件 ] ──▶ 輸出 ──▶ 和輸入比對 ──▶ 圖表、數字
```

例如送一個純淨的 1 kHz 正弦波進去，如果出來多了 2 kHz、3 kHz 的成分，就代表插件會產生諧波（失真）。

### 2. dB 是比例，不是絕對大小
- **dB**：兩個數值的比例，取對數。**+6 dB ≈ 大 2 倍，−6 dB ≈ 小一半，−20 dB = 1/10，−60 dB = 1/1000**。
- **dBFS**：以數位滿刻度（Full Scale，數位能表示的最大值）為 0 dB。所以訊號都是 0 dBFS 以下的負數，−6 dBFS 就是滿刻度的一半。
- **dBc**：相對於主要訊號（Carrier，載波）的大小。「H3 −40 dBc」代表三次諧波比基本頻率小 40 dB（1/100）。

### 3. 兩條 chain 和幾個切換鈕
| 介面元素 | 作用 |
|---|---|
| **Chain 1 / Chain 2** | 兩條各 6 格的插件串。曲線顏色：Chain 1 是橘／黃，Chain 2 是青／淺藍 |
| **1\|2 ↔ 1-2** | 1\|2：兩條 chain 的結果同時顯示。1-2：顯示「Chain 1 減 Chain 2」的差值（粉紅色），曲線越接近 −∞ 代表兩者越一樣（null test，抵銷測試） |
| **L/R ↔ M/S** | 分析左右聲道，或 Mid（中間＝左右的共同部分）／Side（兩側＝左右的差異）。Side 用來看插件有沒有改變立體聲寬度 |
| **Store / Clear** | 把目前的曲線存成虛線，調整參數後可以對照前後差異 |
| **Off / Play 1 / Play 2**（插件版） | DAW 軌道上聽到的是原音、經過 Chain 1，還是經過 Chain 2 |

## Linear（線性分析）：插件把各頻率放大或縮小多少

**適用：** EQ、濾波器，以及任何想知道「音色有沒有被改變」的插件。

### 測試訊號
| 選項 | 送什麼 | 什麼時候用 |
|---|---|---|
| **Delta** | 一個瞬間的脈衝（只有第一個樣本有值，其他都是 0）。它包含所有頻率，而且每個頻率一樣大 | 預設。速度快、結果精確 |
| **Noise** | 白噪音，平均 8 段後計算 | 插件對脈衝反應奇怪時（例如有動態處理），用噪音比較接近真實音樂 |

**Level** 是測試訊號的大小。線性的插件不管多大聲結果都一樣；如果改了 Level 曲線就跟著變，代表插件不是線性的，例如帶有飽和或壓縮。

### 視圖
| 視圖 | 在測什麼 | 怎麼看 |
|---|---|---|
| **Magnitude（頻率響應）** | 每個頻率被放大或縮小多少 dB | 平的 0 dB 線＝完全不改變音色。在 1 kHz 鼓起 +6 dB＝在 1 kHz 推了 6 dB 的 EQ |
| **Phase（相位）** | 每個頻率被延遲了多少「角度」 | EQ 調整的地方，相位通常也會轉動，這是正常現象。線性相位（linear-phase）EQ 的相位會是平的 |
| **Group delay（群延遲）** | 每個頻率實際被延遲了多少毫秒 | 平的＝所有頻率同時到達。低頻比較高＝低頻比較晚出來，打擊樂的衝擊感可能會變鈍。一條水平的非零線＝插件有延遲但沒有回報給 DAW |
| **Impulse（脈衝響應）** | 輸出端收到的脈衝長什麼樣子 | 一根乾淨的直線＝沒有染色。脈衝前出現「預響」（pre-ringing）＝線性相位處理的特徵 |
| **Crosstalk（串音）** | 只從左聲道送訊號，右聲道漏出多少（反之亦然） | 獨立處理左右的插件會顯示「< −200 dB」。殘響、立體聲寬度插件、類比模擬的串音特性會有數值 |

## Harmonic（諧波分析）：插件加了多少「料」

**適用：** 飽和器、類比模擬、壓縮器、限幅器、磁帶模擬，以及想確認「乾不乾淨」的插件。

### 基本觀念
送一個純淨的正弦波（例如 1 kHz）進去：
- 輸出只有 1 kHz → 完全乾淨（線性）
- 多了 2 kHz、3 kHz、4 kHz… → 插件產生了**諧波**。這正是類比模擬想要的「溫暖感」或「顆粒感」
  - **偶次諧波**（H2、H4…）：聽起來比較溫暖、圓潤（常見於真空管模擬）
  - **奇次諧波**（H3、H5…）：聽起來比較硬、有咬勁（常見於削波、磁帶模擬）
- 出現不是整數倍的頻率 → **混疊（aliasing）**。這是數位處理的副作用，通常不好聽

### 模式
| 模式 | 在測什麼 | 結果怎麼看 |
|---|---|---|
| **THD** | 單一正弦波產生的諧波 | 右側的頻譜會出現一根根尖峰。上方會列出 THD、THD+N，以及 H2–H9 各次諧波的大小（dBc） |
| **IMD** | 兩個頻率同時送進去（60 Hz + 7 kHz，振幅比 4:1），看它們互相「調變」出的新頻率 | 7 kHz 兩側出現 7 kHz ± 60、±120… Hz 的旁波帶。IMD 比 THD 更接近「真實音樂（很多頻率混在一起）」時的失真 |
| **Sweep 1D** | 逐點換頻率，每個頻率都量一次 | 三種視圖：**THD**（失真隨頻率怎麼變）、**Fundamental**（基本頻率的增益，也就是用正弦波量出的頻率響應）、**Non-harmonic**（非諧波成分，主要是混疊） |
| **Sweep 2D** | 6 秒的連續掃頻，畫成時間-頻率圖（顏色＝大小，紅色最大、藍色最小） | 斜向上的亮線是基本頻率，上面平行的線是諧波。**線撞到頂端後往下反折＝混疊**，是看插件有沒有做好 oversampling 的最直觀方式 |
| **THD vs Level** | 固定頻率，從小聲掃到大聲 | 三種視圖：THD+N、THD、Gain（增益）。乾淨的插件在小音量時 THD 很低；飽和器的 THD 會隨音量升高；硬削波器在臨界點以下是 0，超過後突然跳高 |

### 數字的意思
| 指標 | 意思 | 參考值 |
|---|---|---|
| **THD**（總諧波失真） | 所有諧波加起來，相對於基本頻率有多大 | < 0.01%（−80 dB）：乾淨。0.1–1%：輕微染色。> 5%：明顯飽和、破音 |
| **THD+N**（總諧波失真加雜訊） | THD 再加上雜訊和其他所有不屬於基本頻率的東西 | 永遠 ≥ THD。如果比 THD 大很多，代表雜訊或混疊很多 |
| **H2…H9**（dBc） | 各次諧波相對基本頻率的大小 | 看哪幾次比較大，判斷是偶次（溫暖）還是奇次（偏硬）的特性 |
| **IMD** | 旁波帶加起來相對 7 kHz 的大小 | 越低越乾淨 |
| **Non-harmonic** | 不是整數倍頻率的成分，主要是混疊 | 越低越好。高頻（5–10 kHz）的數值特別能看出有沒有做 oversampling |

> 小提醒：很多類比模擬插件**本來就應該**有失真，THD 高不代表插件不好，要看是否符合設計目的。這些數字最適合用來**比較**兩個插件，或比較同一個插件的不同設定。

## Oscilloscope（示波器）：直接看波形被改成什麼形狀

**適用：** 削波器、飽和器、快速壓縮器。

| 模式 | 在測什麼 | 怎麼看 |
|---|---|---|
| **Time** | 輸出的波形，灰色虛線是輸入 | 正弦波的頂端被切平＝硬削波；被壓圓＝軟削波（例如 tanh 飽和）。也可以改送方波、鋸齒波、三角波 |
| **Waveshaper** | 橫軸是輸入、縱軸是輸出（輸入固定是正弦波） | **轉移曲線**：斜直線＝線性，曲線兩端彎下來＝飽和，水平段＝削波。上下不對稱＝會產生偶次諧波。**Delay** 用來補償額外的相位延遲；曲線變成橢圓圈時，調整它直到收成一條線 |

## Dynamics（動態分析）：音量變化時，插件怎麼反應

**適用：** 壓縮器、限幅器、閘門（gate）、擴展器。

### Ramp（轉移曲線）
音量從小到大一階一階往上送（再往下回來），記錄每一階的輸出大小。

| 看什麼 | 意思 |
|---|---|
| 灰色虛線（unity） | 輸入等於輸出（沒有處理） |
| 曲線開始彎離虛線的地方 | **Threshold（門檻）**：壓縮開始作用的音量 |
| 彎了之後的斜率 | **Ratio（壓縮比）**：斜率 1/4＝4:1 壓縮。水平＝限幅 |
| 轉折處是尖角還是圓弧 | **Knee**：硬轉折（hard knee）或軟轉折（soft knee） |
| 上升（實線）和下降（虛線）不重疊 | **遲滯（hysteresis）**：插件的反應跟「剛才的音量」有關 |

### Attack / Release（反應速度）
送「小聲 → 大聲 → 小聲」三段正弦波，看輸出音量隨時間的變化。

| 看什麼 | 意思 |
|---|---|
| 大聲段開始時，輸出先衝高再被壓下來 | **Attack（啟動時間）**：壓縮器多快開始作用。數字越小，反應越快 |
| 回到小聲段時，輸出慢慢回升 | **Release（釋放時間）**：壓縮器多快放開 |
| 上方的 attack / release 數字 | 增益變化完成 63% 所需的時間（約等於時間常數）。只是近似值，不同廠商對 attack/release 的定義不完全一樣 |

> 時間設定（Time/step）要比插件的 attack/release 長，否則結果會不準。

## Hammerstein（非線性模型）：失真「從哪來、在哪個頻段」

**適用：** 想深入理解類比模擬、或想自己做類比模擬的人。

一般的 THD 只能告訴你「有多少失真」。Hammerstein 模型更進一步，把插件拆成幾條並聯的路徑：

```
         ┌─ x   ─▶ 濾波器 G1 ─┐
輸入 x ──┼─ x²  ─▶ 濾波器 G2 ─┼──▶ 加總 ──▶ 輸出
         ├─ x³  ─▶ 濾波器 G3 ─┤
         └─ ...               ┘
```

| 視圖 | 意思 |
|---|---|
| **Hammerstein filters G(n)** | 每一條路徑的頻率響應。**G1**＝線性部分（就是一般的 EQ 曲線）；**G2**＝產生偶次諧波的部分；**G3**＝產生奇次諧波的部分。例如 G3 只在低頻比較大，就代表這個插件主要在低頻產生失真 |
| **Harmonic responses H(n)** | 第 n 次諧波隨頻率的變化（比較直接的量測值） |

> 小音量時高階的 G 會很接近 0，數值會有雜訊，這是正常的。Order（階數）選 3–5 通常就夠了。

## Reverb（殘響分析）：聲音拖了多長、怎麼衰減

**適用：** 殘響、延遲效果。

| 視圖 | 在測什麼 | 怎麼看 |
|---|---|---|
| **1D → Impulse** | 長達 1–20 秒的脈衝響應 | 一開始是原音（直達聲），之後是殘響尾巴 |
| **1D → Decay (dB)** | 包絡（實線）和能量衰減曲線 EDC（虛線） | EDC 越平直，衰減越自然 |
| **2D** | 衰減瀑布圖：橫軸時間、縱軸頻率、顏色是大小 | 高頻比低頻先消失＝殘響有做高頻阻尼（damping），聽起來比較自然 |

| 數字 | 意思 |
|---|---|
| **RT60** | 聲音衰減 60 dB（變成 1/1000）所需的時間，最常用的殘響長度指標 |
| **T30 / T20** | 用衰減 −5 到 −35 dB（或 −25 dB）那一段推算的 RT60。兩者接近代表衰減很均勻 |
| **EDT**（早期衰減時間） | 用最前面 10 dB 推算的時間。跟聽感上「殘響有多長」最相關 |

## Performance（效能）：插件吃多少 CPU

| 曲線 | 意思 |
|---|---|
| **實線（signal）** | 處理噪音訊號時，花費的時間占即時的百分比 |
| **虛線（silence after signal）** | 訊號結束後、處理靜音時的時間 |

橫軸是 block size（DAW 一次交給插件多少樣本，16–4096）。

- 一般來說，block 越小、比例越高（每次呼叫都有固定開銷）。
- 某個特定大小突然變高 → 插件內部可能在重新配置記憶體，或緩衝處理不平均。
- **虛線比實線高很多** → 很可能是 **denormal（次正規數）問題**：殘響或濾波器的尾巴衰減到極小的數值時，某些 CPU 處理這種數字會慢上數十倍。寫得好的插件會避免這個問題。

## Specs（規格表）：一次看完標準數據

依照音訊設備的標準量測方法（AES17、IEC 60268 等）整理成一張表，兩條 chain 並排顯示，按「Copy table」可以貼到試算表。

| 類別 | 指標 | 在測什麼 | 好的表現 |
|---|---|---|---|
| Level & latency | **Gain** | 997 Hz、−20 dBFS 時的增益 | 依設計而定，0 dB＝不改變音量 |
| | **Reported latency** | 插件告訴 DAW 自己會延遲多少樣本 | — |
| | **Impulse peak after compensation** | 扣掉回報的延遲之後，脈衝峰值在哪裡 | 0＝回報正確。不是 0＝延遲回報錯誤，會和其他軌錯位（線性相位、look-ahead 設計例外） |
| | **DC offset** | 靜音輸入時，輸出有沒有直流偏移 | < −200 dBFS（完全沒有） |
| Frequency response | **Deviation 20 Hz–20 kHz** | 頻率響應最高和最低差多少 | 不打算改音色的插件應該接近 0 dB |
| | **−3 dB points** | 低頻和高頻在哪裡掉了 3 dB | 越寬越好（除非是刻意的頻寬限制） |
| Distortion | **THD / THD+N** | 見 Harmonic 章節（−1 dBFS 和 −20 dBFS 兩種音量） | 依設計而定 |
| | **IMD** | SMPTE 互調失真 | 越低越乾淨 |
| | **Non-harmonic** | 5 kHz、10 kHz 的混疊加雜訊 | 越低越好，常見的好表現是 −90 dB 以下 |
| Noise | **Idle output noise** | 沒有輸入時，插件自己發出多少雜訊 | 數位插件通常是 < −200（完全靜音）。類比模擬可能刻意加入雜訊 |
| | **A-weighted** | 依人耳靈敏度加權後的雜訊（人耳對低頻和極高頻比較不敏感） | 比未加權更接近聽感 |
| | **Dynamic range (AES17)** | 最大訊號和雜訊底之間的距離 | 越大越好，> 120 dB 已經非常好 |
| Stereo | **L/R gain mismatch** | 左右聲道增益差 | 0 dB |
| | **Crosstalk** | 左右互相漏出的量 | 獨立處理時 < −200 dB；類比模擬可能刻意保留一點 |
| Peak | **True peak** | 把數位樣本之間的真實波形還原後的最大值（dBTP） | 母帶處理通常要求 ≤ −1 dBTP |
| | **Inter-sample overshoot** | 真實峰值比樣本峰值高出多少 | 0 dB 最好。削波器、限幅器常出現 overshoot，轉成 MP3/AAC 時可能破音 |
| CPU | **Signal / Silence** | 512 樣本 block 時的 CPU 占比，以及兩者的倍率 | 靜音倍率接近或低於 1 最好，遠大於 1 代表有 denormal 問題 |

## 常見情境：我應該看哪裡？

| 我想知道… | 去看 |
|---|---|
| 這個 EQ 的曲線準不準 | Linear → Magnitude |
| 這個 EQ 會不會讓鼓聲變軟 | Linear → Group delay、Impulse |
| 這個飽和器加了什麼「料」 | Harmonic → THD（看 H2、H3 的比例）、Oscilloscope → Waveshaper |
| 這個插件有沒有做好 oversampling | Harmonic → Sweep 2D（看線有沒有反折）、Sweep 1D → Non-harmonic |
| 這個壓縮器的壓縮比和門檻 | Dynamics → Ramp |
| 這個壓縮器反應多快 | Dynamics → Attack / Release |
| 兩個插件（例如原廠和仿製）有多像 | 兩條 chain 各放一個，按 **1-2** 看差值 |
| 這個殘響有多長 | Reverb → RT60、EDT |
| 這個插件會不會讓 DAW 的延遲補償出錯 | Specs → Impulse peak after compensation |
| 這個插件吃不吃 CPU | Performance、Specs → CPU |
| 想快速得到一份完整規格 | Specs |
